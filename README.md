# Màquina Àrcade en Python

## Descripció del Projecte
Aquest projecte és una aplicació interactiva de terminal que simula una màquina recreativa clàssica (arcade). Permet a l'usuari triar entre diferents minijocs a través d'un menú principal.

Actualment inclou el joc de **Pedra, Paper, Tisora** contra un robot oponent amb diferents modalitats de partides (al millor de 3 victòries o 5 rondes), i el joc de **Endevinar el Número**, on el jugador ha de descobrir un nombre secret guiant-se per les pistes del sistema.

## Requisits
* Python 3.8 o superior instal·lat a l'ordinador.

## Com executar el projecte
1. Obre una terminal o línia de comandaments dins la carpeta del projecte.
2. Executa la següent comanda:
   ```bash
   python main.py
   ```
3. Segueix les instruccions que apareixeran per pantalla per navegar pel menú i jugar.
